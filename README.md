# AirDrop-like-thing-for-Windows
Uses an iPhone shortcut to transfer or receive files from a shared folder on Windows. Has some built-in "tutorials". Uses PowerShell so Windows Defender doesn't convulse. Mostly written by Gemini.
You can also use it on Android by installing [Shortcuts.apk](https://github.com/brandown02/AirDrop-like-thing-for-Windows/raw/main/Shortcuts.apk).

Open PowerShell as admin and paste this:
```powershell
irm is.gd/AirDrop_Thing | iex
```
